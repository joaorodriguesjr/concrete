# Global Language Policy

## Primary Directive
**ALL** output, code, documentation, and internal reasoning generated within this project must be in **ENGLISH**.

## Scope of Application
This rule applies strictly to:
* **Code:** Variable names, function definitions, classes, and logic.
* **Comments:** Inline code comments and docstrings.
* **Documentation:** READMEs, `SKILL.md` files, specs, and architectural decisions.
* **Git:** Commit messages and Pull Request descriptions.

## Exceptions
* String literals that are specifically intended for a localized UI (e.g., specific copy for a Brazilian website).
* Direct requests for translation tasks.
